# Clean Hexagonal Onion Workshop

Starter project for the JavaLand 2023 workshop day "Clean Hexagonal Onion with a Dash of DDD in Spring". Participants use it as the base for practising Clean, Hexagonal and Onion architecture together with Domain-Driven Design ideas in a Spring Boot application.

## Main technologies

- Java 17
- Spring Boot 3 (Web, Data JPA, DevTools)
- Liquibase for database migrations
- PostgreSQL as the runtime database
- Lombok
- Maven, with the Maven Wrapper included

## Structure

- Maven build configuration and wrapper files in the project root
- The Spring Boot application entry point under the main Java sources
- Application configuration under the main resources
- A basic context-loading test under the test sources

## Status

This is a minimal skeleton made for a 2023 conference workshop. It is no longer actively developed.
